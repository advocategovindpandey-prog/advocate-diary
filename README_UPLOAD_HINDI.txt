ADVOCATE DIARY — GITHUB PAGES PACKAGE

इस ZIP की सभी फाइलें अपने मौजूदा GitHub Pages repository के ROOT में अपलोड/replace करें।

शामिल फाइलें: index.html, master.html, admin.html, user.html, sw.js, तीनों manifest और छह icons।

महत्वपूर्ण:
1. master.html, admin.html और user.html आपकी अभी दी गई नवीनतम फाइलें हैं; इन्हें इस पैकेज में बिना बदलाव रखा गया है।
2. इन तीन HTML फाइलों के login/authentication और server connection code को इस पैकेजिंग में नहीं बदला गया।
3. firestore.rules, firebase.json, .firebaserc और functions/ को जानबूझकर शामिल नहीं किया गया है। इन्हें GitHub/Firebase से delete या replace न करें।
4. यह पैकेज GitHub Pages की फाइलें व्यवस्थित करता है; लाइव Firebase permission-denied समस्या ठीक होने की पुष्टि नहीं करता।
